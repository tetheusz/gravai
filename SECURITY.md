# Security Policy

## Reporting a Vulnerability

GravAI is a hackathon prototype forked from Circle's arc-nanopayments sample and
runs on **Arc testnet only**.

Please do not file public GitHub issues for security vulnerabilities that involve
live secrets or funded wallets. Instead email the maintainer via the GitHub
profile on [github.com/tetheusz/gravai](https://github.com/tetheusz/gravai).

Upstream Circle / nanopayments vulnerabilities should still be reported through
Circle's [Bug Bounty Program](https://hackerone.com/circle-bbp).
